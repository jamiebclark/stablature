# Tasks: Import ASCII tab by pasting text

**Input**: Design documents from `/specs/004-ascii-import/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/ (reader.md, writes.md, components.md, round-trip.md), quickstart.md

**Tests**: The plan makes invariant probes mandatory and names the test files. They are listed as the first tasks of each phase and each one must FAIL on the pre-change code (the module or behaviour it probes does not exist yet, or does not hold yet). Probes live in the project test suite, never a temp dir.

**Organization**: grouped by user story. US1, US2 and US3 are all P1. US4 is P2. `parse.ts` is one file that grows across US1 to US3, so those phases are sequential on it. The Playwright specs run against a production build, so never run them while a dev server holds `.next`. Run every command synchronously with `< /dev/null`.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: different files, no dependency on an incomplete task
- Line endings: keep each file's own. `SongView.tsx`, `clipboard.ts`, `model.ts`, `protocol.ts`, `text.ts`, `techniques.ts` are LF. `src/components/ui/index.tsx` is CRLF and is NOT touched.
- Zero diff required (INV-026): `src/lib/export/ascii.ts`, `src/lib/tab/layout.ts`, `src/components/tab/TabStaff.tsx`, `ascii.test.ts`, `text.test.ts`, `clipboard.test.ts`, `drizzle/`, `src/db/`, `src/lib/server/`, `src/app/api/`, `src/lib/local/db.ts`. Edit no existing test file; new cases go in new files.
- Read `node_modules/next/dist/docs/` before touching any Next.js API (AGENTS.md). Only a client component is added, so little is expected.
